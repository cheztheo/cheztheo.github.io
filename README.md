# Chez Theo — GitHub Pages

Chez Theo 的手绘房间网站。直接使用上传的绘画和 Logo 素材，无需构建即可通过 GitHub Pages 发布。

## 上传到 GitHub

1. 打开 `https://github.com/cheztheo/cheztheo.github.io`
2. 点击 **Add file → Upload files**
3. 将 ZIP 解压后，把全部 HTML、CSS、JS 文件和整个 `assets` 文件夹拖进去；文件应位于仓库根目录
4. 点击 **Commit changes**
5. 在 **Settings → Pages** 中选择 `Deploy from a branch`、`main`、`/ (root)`

发布后访问：`https://cheztheo.github.io/`

## 已实现

- 白天 2 分钟 → 黄昏渐变 1 分钟 → 夜晚 2 分钟 → 黎明渐变 1 分钟

- 白色旋转小旋风鼠标；只有接近火苗才会吹动火苗，点击不生成额外白圈
- 网球向右弹跳两次（先高后低）后离开画面，最高处不超过椅背中部，刷新页面才会回来
- 电脑、《少女心事》和墙上画作可点击打开作品弹窗；摄影集已删除
- 按透明 PNG 的真实轮廓识别点击区域，透明空白处不会触发交互
- 仅这三件物品悬停时放大 2.5%，以各自物品的中心缩放
- 点击和悬停没有白色边框、光圈或标签气泡；支持 Tab 和回车操作
- 电脑包含白天、夜晚两层，两层亮度均为 75%
- 背景在白天和夜晚都覆盖整个窗口；物品保持原位、等比例完整显示
- 月光与阴影连续延伸到屏幕边缘，不在原 16:9 画布处截断
- 夜间月光由阴影 1 缓慢移动到阴影 2，地面光形和影子一起变化
- 用最新上传的蜡烛、光圈、《少女心事》和 JPG Logo
- 叶片从原来的合层画中按颜色和轮廓分离，可拖动两片主叶，花瓶保持原位
- 自适应电脑、平板和手机屏幕

## 文件

- `room-state.js`：地灯先亮，1 秒后水晶灯与环境光同步亮，再过 0.8 秒烛光亮
- `object-interactions.js`：真实轮廓点击、悬停和键盘访问
- `scene-renderer.js`：原素材合成、混合模式、阴影移动、网球和叶片绘制
- `script.js`：页面交互、鼠标风和叶片拖动

透明轮廓由浏览器在图片加载后自动计算。请通过 GitHub Pages 或 HTTP 本地服务打开；直接以 `file://` 打开时，浏览器可能限制图片像素读取。

## 当前灯光分组与鼠标

`lighting-preview/` 保存已校准的独立透明灯光图层；环境光始终读取水晶灯的淡入值。地灯和椅子受光保留 60% 的效果，桌面环境光为 50%，水晶灯、烛光保留 80% 的效果。火苗与近处光晕合成同一组，使用同一角度和支点随风摆动。电脑亮起时只提亮屏幕，保留键盘与机身的原有亮度。

较大的环境光和预览底图使用 PNG 分片，由 `image-tiles.js` 按清单还原为完整画布；地灯使用无损 WebP。它们与原始 PNG 的 RGBA 像素完全一致，便于上传并减少单个请求的大小。

亮灯预览页与首页共用场景渲染器和交互逻辑，加载后直接从夜晚开始，可点击「重新亮灯」重播，或点击「查看月光末帧」检查右下边缘。

灰白龙卷风鼠标保留台风眼，外缘以圆形柔和透明遮罩去除四角。普通大小 21px、旋转周期 1.8 秒；靠近火苗时为 28.5px、周期 1 秒。logo 使用去白底的透明 PNG，在夜色层下面绘制。花瓶与叶片保持原素材静止。

月光直接使用原始第二帧的两块白色区域与纸纹，作为一组从左上向右下平移。保留原轮廓、大小与相对间距，不缩放、不生成新光斑、不叠加两张图；末帧整体向右 32px、向下 24px 平移，让白色月光通过右、下边缘。

背景改用用户确认的扩展浅粉底图，以无损 WebP 分片加载，保留原图的 RGB 与透明度。
