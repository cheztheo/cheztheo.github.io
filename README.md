# Chez Theo — GitHub Pages

Chez Theo 的手绘房间网站。直接使用上传的绘画和 Logo 素材，无需构建即可通过 GitHub Pages 发布。

## 上传到 GitHub

1. 打开 `https://github.com/cheztheo/cheztheo.github.io`
2. 点击 **Add file → Upload files**
3. 将 ZIP 解压后，把全部 HTML、CSS、JS 文件和整个 `assets` 文件夹拖进去；文件应位于仓库根目录
4. 点击 **Commit changes**
5. 在 **Settings → Pages** 中选择 `Deploy from a branch`、`main`、`/ (root)`

发布后访问：`https://cheztheo.github.io/`

## 文件

- `room-state.js`：地灯先亮，1 秒后水晶灯与环境光同步亮，再过 0.8 秒烛光亮
- `object-interactions.js`：真实轮廓点击、悬停和键盘访问
- `scene-renderer.js`：原素材合成、混合模式、阴影形变与网球绘制
- `shadow-morph.js`：保留两张上传阴影的起终点轮廓，连续变形两块月光区域
- `approved-night.js`：将确认的夜景颜色应用到原有动画分组，保留亮灯顺序、月光平移、悬停、网球与烛光互动
- `script.js`：页面交互、鼠标风和叶片拖动

透明轮廓由浏览器在图片加载后自动计算。请通过 GitHub Pages 或 HTTP 本地服务打开；直接以 `file://` 打开时，浏览器可能限制图片像素读取。

## 当前灯光分组与鼠标

`lighting-preview/` 保存已校准的独立透明灯光图层；环境光始终读取水晶灯的淡入值。地灯和椅子受光保留 60% 的效果，桌面环境光为 50%，水晶灯、烛光保留 80% 的效果。火苗与近处光晕合成同一组，使用同一角度和支点随风摆动。电脑亮起时只提亮屏幕，保留键盘与机身的原有亮度。

较大的环境光和预览底图使用 PNG 分片，由 `image-tiles.js` 按清单还原为完整画布；地灯使用无损 WebP。它们与原始 PNG 的 RGBA 像素完全一致，便于上传并减少单个请求的大小。

亮灯预览页与首页共用场景渲染器和交互逻辑，加载后直接从夜晚开始。昼夜和灯光自动播放，没有重新亮灯、跳到末帧或其他手动调节按钮。

灰白龙卷风鼠标保留台风眼，外缘以圆形柔和透明遮罩去除四角。发光单独绘制在云层外侧，保留透明的中央风眼。普通大小 21px、旋转周期 0.9 秒；靠近火苗时为 28.5px、周期 0.5 秒。logo 直接取自确认的桃子原稿，去掉白底，并使用与夜影一致的正片叠底颜色。

天刚黑时使用上传的《夜晚阴影1(1).PNG》的原始短形状。夜晚的两分钟内，两块月光区域各自连续拉长、变形并向右移动，最终变成《夜晚阴影2.PNG》的形状。两张原始 PNG 不修改；形变使用对应的轮廓网格，并在同一片变形区域内采样纸纹。起终点直接读取原始遮罩，避免跳变与重复光斑。末帧沿用原有向右 32px、向下 24px 的位置。

背景直接使用用户上传的 IMG_1967 2.PNG，保存为 assets/background-original.png；文件字节、2048×1152 分辨率与透明度均保持不变。背景独立缩放至窗口宽度，每侧多覆盖 2px，家具和其他物品仍按原来的坐标和比例显示。粉色背景位于蓝色夜影下。

最终夜景以确认的图片为颜色与灯光依据，使用无损 WebP 分片保存。`approved-night.js` 保留原动画渲染器，物品与火苗的颜色校准随对应物品移动。月光只移动原来的光斑遮罩，先移除末帧阴影的影响，再按当前月光位置重新着色，避免把球拍、网线等物件细节带进白色光斑。桌椅、球拍和网球直接采用上传的原始 3840×2160 PNG 和原有灯光合成，不使用参考截图中经过重绘的物件像素。PNG 文件不压缩、不锐化、不重绘；桌椅与球拍在最终显示变换下直接从原图绘制，网球动画也直接读取原图。画布按设备像素比例渲染，取消 1440×960 的显示分辨率限制。白天保留原有场景。楼梯和左侧小房子使用上传背景中的完整原笔触；背景只按显示宽度放大，每侧外扩 2px。背景光照以独立柔和光场合成，避免将参考截图里的旧建筑线条再次叠入背景。

桌面和格子布只调整独立光照贡献，保留原始物件和格子笔触。光照相对未亮灯场景做均匀化，杯子、花瓶、书、笔和电脑附近的原有投影单独保护。桌面光仍跟随水晶灯和环境光的原有淡入，不提前亮起。形变月光中的空白地面保持干净，并按物件的真实轮廓保护家具、球拍和移动网球。
