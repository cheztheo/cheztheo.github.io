# Chez Theo — GitHub Pages

这是 Chez Theo 个人网站的第一版，无需安装任何软件即可发布。

## 上传到 GitHub

1. 打开 `https://github.com/cheztheo/cheztheo.github.io`
2. 点击 **Add file → Upload files**
3. 将 ZIP 解压后，把 `index.html`、`styles.css`、`script.js` 和整个 `assets` 文件夹拖进去
4. 点击 **Commit changes**
5. 在 **Settings → Pages** 中选择 `Deploy from a branch`、`main`、`/ (root)`

发布后访问：`https://cheztheo.github.io/`

## 已实现

- 白天 2 分钟 → 黄昏渐变 1 分钟 → 夜晚 2 分钟
- 夜晚时地灯、蜡烛、水晶灯每隔约 1 秒依次亮起
- 鼠标靠近烛光时，火焰会被“风”吹歪
- 点击右下角网球后，网球弹起并飞出画面，刷新页面才会回来
- 摄影集、《少女心事》和墙上画作可点击打开作品弹窗
- 自适应电脑、平板和手机屏幕
